# ◈ Siphon v1.1.2

**The real video, not the advert next to it.**

</div>

---

A fix release on top of **v1.1.1**. Your saved sites, queue, history and rclone
setup carry over as they are; if you are on v1.1.1 the app offers the update by
itself.

## 🐛 Fixed

### Short adverts were downloaded instead of the video
Some sites do not write the address of their video into the page. They hide the
player's settings in a *packed* script (`eval(function(p,a,c,k,e,d){…})`), and
the only plain video file left on the page is an advert or a preview clip. Siphon
found that clip, took it for the video and saved a few seconds of nonsense in
place of an hour-long film — and, with automatic upload on, sent it to the cloud
too.

- **Packed scripts are now unpacked** and searched like the rest of the page, so
  the real playlist is found. A playlist is always tried before a loose video
  file.
- **A safety check on the finished file.** When the page says how long its video
  is, a file far too small for that length (say 2 MB for a 60-minute video) is
  not kept: Siphon tries the next address the page lists, and if none is left it
  says the file looked like an advert or a preview instead of saving it. Short
  videos and pages that do not state a length are never judged.
- **The log names the video server** a download came from, so a wrong pick is
  easy to spot.

### Site names and slogans in file names
Titles such as `ABC-123 - SiteName ｜ Watch HD Online` now become `ABC-123`.
Only a trailing *site name* (and whatever slogan follows it) is removed; a title
whose own words contain a dash, like `Love story - Part 2`, is left alone.

## 🔒 Privacy

- **Upload lines in the log file no longer name your files or cloud folders.**
  Download lines already hid them; upload lines now do too
  (`[Upload] Done: <hidden>`). The error text of a failed upload is kept, so a
  problem can still be diagnosed. The live console still shows everything.
- Example sites in the source code and its history are now neutral
  (`example.com`).
