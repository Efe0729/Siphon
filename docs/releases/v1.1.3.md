# ◈ Siphon v1.1.3

**Automatic update checks on launch, safer closing, and one-click Drive account cleanup.**

</div>

---

A quality-of-life release on top of **v1.1.2**. Your saved sites, queues, history and rclone setup carry over as they are.

## ✨ New

### Automatic update check & live download progress
- **Checks for updates when opened.** Whenever you start Siphon, it checks GitHub Releases in the background and pops up a clean prompt offering **Update now** or **Not now** when a newer version is available.
- **Live download progress & SHA-256 verification.** Clicking **Update now** shows a live progress bar inside the prompt (and on the sidebar version badge) while downloading `Siphon.exe`, and verifies its SHA-256 digest against `Siphon_SHA256SUMS.txt` before restarting.
- **Cleaner release note preview.** HTML tags and headings are stripped when showing a release summary inside the app.

### Remove a cloud account from the Upload tab
- Added a **Remove** button next to the cloud account actions in the Upload tab so stale or broken rclone remotes can be removed with confirmation without touching files already uploaded to Google Drive.

### Active transfer protection when closing
- Closing the window while downloads or cloud uploads are actively transferring now asks for confirmation first, preventing accidental interruption of in-progress uploads. Auto-update restarts bypass this prompt automatically.

## 🐛 Fixed
- **PyInstaller DLL error after in-app updates:** Cleared PyInstaller bootloader environment variables (`_PYI_*`, `_MEIPASS*`) when launching the updated executable via the helper batch script, preventing `"Failed to load Python DLL ...\_MEI...\python312.dll"` on restart.
